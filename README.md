# Student Portfolio Website

## Mini Project Submission Package

A responsive student portfolio website developed using **HTML5, CSS3 and JavaScript**.

### Features
- Responsive desktop/tablet/mobile layout
- Modern hero section
- About Me section
- Technical Skills cards
- Project cards
- Education timeline
- Responsive navigation menu
- Smooth scrolling
- Scroll-based active navigation
- Hover animations
- Client-side contact-form validation
- Success/validation feedback
- Beginner-friendly source structure

## How to Run

1. Extract the ZIP file.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

For the easiest development workflow, install the **Live Server** extension in VS Code and select:
`index.html` → **Open with Live Server**.

No Python, Node.js or database is required for the current version.

## Important

The contact form is intentionally a **front-end demo**. It validates the entered name, email and message, but it does not send an actual email because no backend/email service is connected.

Before final college submission, replace the placeholder contact information and project links with your actual details.
